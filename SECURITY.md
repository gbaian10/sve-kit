# Security policy

Please report suspected vulnerabilities privately to
[contact@svekit.app](mailto:contact@svekit.app). Do not open a public issue containing
exploit details, credentials, or private test data. Include the affected version
or commit, impact, and a minimal reproduction using synthetic data where possible.
Do not send active passwords or tokens.

This project is maintained by one person. Security fixes target the current main
branch; there is no long-term support commitment for older versions. The
maintainer will review reports and coordinate remediation and disclosure with the
reporter. No fixed response time is guaranteed.

The same address accepts rights concerns and removal requests; see LICENSING.md.
