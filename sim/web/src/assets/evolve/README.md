# EVOLVE badge

`evolve.svg` is a hand-drawn vector modelled on the black plaque above the
illustration on newer official cards: gold lettering and slanted sides. It is
not a crop of an official image. All evolve cards use this one badge, including
older printings and both regions.

Visual references: Japanese SP01-049 (2024) and English BP01-003EN (2023),
using the card images linked by their official card pages:
[JP SP01-049](https://shadowverse-evolve.com/cardlist/cardsearch/?cardno=SP01-049),
[EN BP01-003EN](https://en.shadowverse-evolve.com/cards/?cardno=BP01-003EN).
The drawing was produced with Codex gpt-6.1-sol. The imitated official design is
excluded from the project's license grants; our drawing uses Apache-2.0.
See [LICENSING.md](../../../../../LICENSING.md).

Glyphs are paths converted from **Liberation Serif Bold 2.1.5**, under SIL Open
Font License 1.1. Font source: [Liberation Fonts](https://github.com/liberationfonts/liberation-fonts).
The font's copyright and license are in [OFL.txt](../rarity/OFL.txt).
No font file or runtime font lookup is needed.
