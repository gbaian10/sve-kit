# Card labels

These are hand-drawn SVGs modelled on labels printed on official cards, not crops
of official images. All printings and both regions use the same drawings.
The drawings were produced with Codex gpt-6.1-sol.

| Files                                                  | Drawing and visual references                                                                                                                                                                                                                                       |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `evolve.svg`, `advance.svg`, `leader.svg`, `token.svg` | Black plaques with gold lettering and slanted sides, based on the newer EVOLVE label above the illustration (JP SP01-049, 2024; EN BP01-003EN, 2023). ADVANCE lettering was checked against JP BP21-PR13. LEADER and TOKEN deliberately use this same plaque style. |
| `follower.svg`, `spell.svg`, `amulet.svg`              | Rounded labels with white lettering on red, purple and teal backgrounds. Checked against JP BP01-029, BP01-063, BP01-150 and newer BP21-T01, BP21-012, BP21-018 (2026), which retain those colours and shapes.                                                      |

JP BP20-LD01 (2026) still prints a blue Leader label below the name, and
BP21-T01 (2026) prints a pale Token label in the type line; neither has the black
top plaque. Their words are rendered in uppercase on the shared location plaque
at the maintainer's request. ADVANCE's coloured official frame is also replaced
by the shared black plaque. These are project presentation choices.

References use the images linked from the official card pages, for example
[SP01-049](https://shadowverse-evolve.com/cardlist/cardsearch/?cardno=SP01-049),
[BP20-LD01](https://shadowverse-evolve.com/cardlist/cardsearch/?cardno=BP20-LD01),
[BP21-T01](https://shadowverse-evolve.com/cardlist/cardsearch/?cardno=BP21-T01),
[BP21-012](https://shadowverse-evolve.com/cardlist/cardsearch/?cardno=BP21-012),
[BP21-018](https://shadowverse-evolve.com/cardlist/cardsearch/?cardno=BP21-018).

Font copyright and license are in [OFL.txt](../rarity/OFL.txt).
No font file or runtime font lookup is needed.
