# Keyword icons — traced vector reconstructions

The official keyword designs remain the property of Cygames and Bushiroad (© Cygames／Bushiroad).
These six monochrome vector reconstructions were traced from the maintainer's photographs of the
official keyword dice included with Special Starter Set 2025. They contain no text or embedded
bitmap data. Maintainer review of their use and authorization is required before publication.
These designs are excluded from the project's Apache-2.0 license grants; see
[LICENSING.md](../../../../../LICENSING.md).
