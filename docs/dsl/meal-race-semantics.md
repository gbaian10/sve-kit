# 食事與出走的執行語義

食事是起動型的進化相當能力；出走是其效果產生的事件。兩者分開降低與執行，
不產生進化事件。規則依 CR 14.2、8.3.2，以及官方
[Q345–Q350](https://shadowverse-evolve.com/question/faq/)、
[Q382–Q384](https://shadowverse-evolve.com/cardlist/?cardno=CP01-042)；
卡文仍以已審查的卡片輸入為準。

`feed: {times: N, cost: {pp: P}}` 是印刷食事入口的巨集，省略 `times` 為 1。
它展開成食事資源付款、PP 付款，以及效果中的 N 次出走指示。
食事與出走分別使用 `Action::MealRace` 的 `Meal`、`Race` 操作；
前者的數量是付款所需資源張數，後者的數量是事件次數。

宣告食事時，共同的正式打出交易讓控制者以問題內的 handle 選取 N 張未使用的
食事資源，並決定是否以 1 EP 代替費用中的 1 PP。資源身分依規則登錄的
`meal_item` 辨識，不從卡號或聯名名稱推斷；選項只對該控制者與裁判公開。
資源不足、PP／EP 不足、重複或過期的 handle 都不能完成付款。

食事與普通進化共用每回合的進化相當能力額度；已有出走領域連結的從者不能再食事。
付款將所選資源從控制者的進化牌堆移至出走領域並關聯到持有者。
成功付款後才完成能力打出，隨後逐次產生 `RaceEvent`，共用既有待機能力佇列。
事件中的 `link` 指向持有者的一個有效食事關聯，不表示第 N 次出走消耗第 N 張資源。
目前不提供逐資源的事件讀值。
`race_time` 訂閱自身出走，可沿用正式目標、頭付款與模式等共同程序。

從者出走後，在相關資源仍位於出走領域期間具有突進；目前出走狀態與事件歷史分開。
`exists` 的公開區域選取可用 `racing: true` 查詢當前狀態。
從者離場時沿共同離場程序解除連結，相關資源依規則表面朝上放回擁有者的進化牌堆，
同場對局不能再次用於食事。出走不禁止該從者於之後的回合進化。

目前作者入口接受固定食事次數、固定 PP 費用、自身 `race_time`，
以及對已有食事關聯之自身的固定次數 `race`。一般食事本文、
監看其他物件出走的訂閱、無資源關聯的直接出走與出走歷史讀值仍須另外接通。
