# 已審查的解析卡片輸入以純文字進版控

來源 HTML 的重新解析依賴私人歸檔，也使卡文變更難以在 PR 逐欄審查；因此將保留完整來源識別與歷史觀測的日英解析輸入保存到 `card-data/`，原始歸檔繼續保留，使用者仍只讀 carddb 快照。相較每包壓縮檔，純文字 JSON 提供直接可讀的 diff 與一般工具讀取，Git 自身也會壓縮與增量保存；代價是工作目錄較大與官方內容進入公開歷史，依既有授權排除政策處理。單檔超過 1 MiB 的包採固定每 200 號區段，避免新增卡片造成既有檔案重新分配；完整欄位、序列化及驗證見[解析輸入契約](../schema/ingest/parsed-card-inputs.md)。
