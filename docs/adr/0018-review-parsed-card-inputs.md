# 已審查的解析卡片輸入以純文字進版控

來源 HTML 的重新解析依賴私人歸檔，也使卡文變更難以在 PR 逐欄審查；因此將日英解析輸入與來源觀測保存到 `card-data/`，作為「能重新產生的不進 git」的明示例外。選擇解析層，是為了保留官方來源差異與重建證據，同時讓人工採納、翻譯、跨地區對應及匯出格式繼續獨立演進；保存合併後建置資料或公開快照會混入這些下游決定。原始歸檔繼續保留，使用者仍只讀 carddb 快照。

相較每包壓縮檔，純文字 JSON 提供直接可讀的 diff 與一般工具讀取，Git 自身也會壓縮與增量保存；代價是工作目錄較大與官方內容進入公開歷史，依既有授權排除政策處理。欄位、分檔、序列化與驗證由[解析輸入契約](../schema/ingest/parsed-card-inputs.md)規範。
