# 集中裁定並逐結論保留證據強度

只在每張卡附 Q&A 網址會丟失採決時的來源版本，也容易把整族類推當成官方直接答案。裁定集中登錄，逐結論區分 official、generalized、inferred、undecided，透過版本與部分取代保存仍有效範圍，讓來源更新能反查受影響用途；代價是維護引用與適用域，但不以使用者接受或測試通過冒充官方證據。資料封套與提示責任見 [IR §11](../dsl/ir-vocabulary-1.0.md#11-裁定登錄與證據型別)及[四層契約 §9](../schema/domains/four-layer-translation.md#9-舊模板重鍵與裁定引用)。
