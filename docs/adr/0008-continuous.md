# 持續特徵求值與事件提交分離

直接修改印刷數值或把查詢前後的數字差當事件，會讓持續效果重算改變遊戲，亦無法區分進化與超進化。採共用的純特徵求值器，按規則層次、依存與時間序套用效果，事件另由明示數值處理提交；承擔動態依存及時間序的成本，避免固定 set/add 順序或反覆求數值固定點造成錯誤。求值、取代與推定強度見 [IR §9](../dsl/ir-vocabulary-1.0.md#9-特徵持續效果取代及規則許可)、[§14](../dsl/ir-vocabulary-1.0.md#14-持續效果與使用額度補充)與 [GAP-S-008](../dsl/ir-vocabulary-1.0.md#gap-s-008)。
