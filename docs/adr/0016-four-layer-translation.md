# 翻譯與 DSL 共用四層來源綁定

整行模板的固定譯詞使改名、量詞及加粗位置分散，DSL 再抽一次來源也可能得到不同的值或角色；拆成單句則會丟失跨句費用、結果與作用域。翻譯採術語葉、有限文法形式、可部分覆蓋的封閉名詞片語與整行句框架，三種消費者共用已驗來源綁定，以維護有限文法及來源位置的成本換取語義一致，且不以 NP 全覆蓋或 DSL 完成作翻譯前置。身分、接口依賴、裁定重鍵及 JP 翻譯基線依[四層契約](../schema/domains/four-layer-translation.md)與[翻譯契約](../schema/domains/translation-contract.md)，巨集資格另依[撰寫語法 §10](../dsl/author-syntax-1.0.md#10-巨集規範)。
