# ADR-0005：物件世代、LKI 與合法跨區追蹤

狀態：已採用（2026-09-28）。規則版本：CR 1.27.0。

## 背景

CR 4.1.4 把一般跨區視為新物件；進化和場間控制移轉另有規則。BP13-SL16 的 Q1776 顯示同時放アルザード與紅の牙到 EX，在只剩一格時可只放紅の牙，アルザード留墓地。後句「EX 的這張卡放 counter」不能靠卡號找到墓地那張並強行操作。

BP14-046 對本次移到 EX 的卡給下一次免費打出；這需要限定於實際移動成果的新物件，而不是永久追同一張實體牌。BP12-109 的 Q1709 又需要讀已離場來源的傷害限制，證明「可讀最後資訊」與「仍可對它施作」必須分開。CR 10.11、4.8.3.3、10.6.2.1.3 及 10.6.2.8.1.1 分別提供 LKI 與有限攜帶路徑。

## 決定

R.object 包含 ObjectId 與 Generation；R.target 保存選定條件與世代。R.lki 只提供規則資訊，無執行權。R.follow-move 指向 receipt 成功成員的 after ref，並帶 SameEffectExplicitReference、TriggerExplicitReference 或已登錄 RuleCarry 授權。卡號／卡名是印刷識別，不能代替物件身分。

follow 無成功成員時，後續集合動作依 CR 1.3.2 不做，不是載入錯誤。若變成新世代又移走，舊 follow 不追下一代；沒有合法 binding／授權則載入拒絕。BP13-SL16 放紅の牙時不加アルザード counter；同卡號另有副本也不能承接。

EX→解決區→場的效果與 counter 只沿指定規則攜帶。BP14-046 安裝時捕捉成功 after 集合，玩家共用一次 UsageId，不為每張各建免費額度；依日文語法與 CP04-003 同句型推論（無直接 Q&A），登錄為 R-0010，標 `strength: inferred`。來源 holder 與 after refs 分開，lastword 的 this 不因被召回就改成新的傷害來源。

客戶端未公開的隱藏物件不得有可跨區追蹤的固定 ID。公開歷史可保留曾見資訊，但不能提供由舊公開物件到目前隱藏 slot 的對應表。

## 考慮過的選項

| 選項                           | 為何不採／採用代價                                                                                |
| ------------------------------ | ------------------------------------------------------------------------------------------------- |
| 固定實體 ID 永遠有效           | 違反換區新物件；同一張回場後會錯誤保留舊目標或折扣，還會讓對手追蹤手牌。                          |
| 找不到引用就用同卡號／卡名補回 | Q1776 的失敗移動會被當成功；多副本時無法判斷是哪一張，不存在可靠補回順序。                        |
| LKI 同時可執行動作             | 能讀來源攻擊力不表示來源仍在場；把快照當 target 會讓已離場物件再次受傷或移動。                    |
| 每次換區完全抹除一切資訊       | 又會破壞規則明示的 EX 攜帶與 Q1709 的 lastword 來源限制。採有限授權可同時保留必要資訊與世代邊界。 |

## 後果

receipt 需要保存成功前後引用，語法略長但錯誤可定位。驗收包含移動成功／取代／容量不足、第二次換區、同名副本、進化仍同世代與觀察匿名化。不得只測最終卡片數。

## 未決事項

匿名 handle 的 wire 格式及更新策略待實作；正式公開協定前需差分測試證明兩種對手隱藏配置產生相同可見資訊。這是實作選擇，不延後「不洩漏固定 ID」的要求。
