# ADR-0020：手寫效果與精確來源錨點分開保存

把逐用途展開引用改成手寫主檔與具名本體，精確來源和版本集中到每包的機器錨點，以減少作者必須維護的欄位；普通讀取仍重算比對，只有明示 write 才能重新綁定。相比只保存摘要，保留 binding／occurrence／frame 等引用可直接診斷失配；相比逐規則 pin／依賴追蹤平台，沿用全域 adapter／expansion 資源 pin 較簡單，但配方變動可能要求多包一起重算，且舊審核不自動續用。這項選擇改變作者儲存與審核基準，回切須先驗證當前內容無損，完整欄位與失效範圍見 [DSL 承載契約](../dsl/author-contract-1.0.md#25-每包機器錨點)。
