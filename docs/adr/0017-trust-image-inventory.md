# 卡圖上傳與快照分開並信任成功清單

文字更新逐張重讀與下載全庫卡圖代價過高。卡圖由獨立 producer 交付公開上傳描述，publisher 信任自己成功寫入的卡圖上傳清單，快照只比對精確版本與大小；JSON 仍直接讀匯出閉包並保留既有比對與讀回。覆寫或刪圖前先條件移除受影響的清單列，全部上傳成功才登錄新列，接受工具外刪換不會被日常發布偵測、失敗必須同輸入重跑及單寫者序列操作的限制，換取未變卡圖零讀檔、零逐圖網路請求。清單與索引保留條件寫入，卡圖改為明示普通 PUT；固定 key、query 版本與保留窗口沿用 ADR-0012／0013，CDN 新鮮度另由維護者驗收。契約與恢復方式見 [publish](../../publish/README.md) 與[圖片交接](../schema/images/image-index.md)。
