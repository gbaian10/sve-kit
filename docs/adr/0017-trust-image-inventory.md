# 卡圖上傳與快照分開並信任成功清單

只改文字也要本機重讀並逐張下載比對全庫卡圖，而單一維護者依序操作時，這些讀取只是在重新確認自己先前成功寫入的內容。卡圖改由獨立指令依產圖交付的上傳描述，只普通 PUT 新增或變動者且不讀回，全部成功後才條件寫入桶內的卡圖上傳清單，覆寫或刪圖前先條件移除受影響列；快照上傳不讀卡圖，只要求清單中的版本與大小精確相符，JSON 仍讀匯出閉包比對、create-only 寫入並讀回。清單只記桶內已成功的結果、不記中斷步驟，不是 ADR-0015 所拒絕的發布帳本；接受工具外刪換不會被日常發布察覺、中斷須以同一輸入重跑、上傳與回收只能單人依序執行、成功只代表 origin 已寫入而 CDN 新鮮度另行驗收，換取未變卡圖零讀檔與零逐圖請求，固定 key、query 版本與保留窗口沿用 ADR-0012／0013，契約見 [publish](../../publish/README.md) 與[圖片交接](../schema/images/image-index.md)。
