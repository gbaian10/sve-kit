# ADR-0011：裁定登錄、證據強度與輔助提示

狀態：已採用（2026-09-28）。規則版本：CR 1.27.0。

## 背景

CP04-P72 的 Q2467 對「拒付不算 UB」有直接回答，但將同樣費用時點推廣到五種關鍵字頭是整族類推（R-0001）。BP08-011 的 Q1061 直接規範兩種 token 各一張，卻沒有直接說一張消滅失敗時選哪種。若只記 Q 號而不記適用範圍，界面容易把推定當成官方答案。

R-0009 依 Q940／Q852／Q2418 修正長寫條件的誘發時檢查；R-0002 結算時判條件的部分仍有效。CR 10.1.1.2.1、10.7.1–.2、10.6.2.8.2 支持這項分離。裁定因此需要可部分取代與版本追蹤，不能只覆寫一段文字。

## 決定

2026-10-09 [#476](https://github.com/gbaian10/sve-kit/issues/476) 落地註記（以下原文為歷史決定）：正式位置改為 `authored/rules/rulings/`，文件封套為 `format: 1, kind: ruling`；裁定證據與原決定不變。

集中登錄 RulingRecord，正式資料位置為 authored/rulings。欄位包括 question、decision、evidence、strength、decided_by、applies_to、hint、supersedes。`applies_to` 型別為 `List<TemplateId | IrElementId>`：句型 ID（`T…`）來自全卡句型分類，IR 元素 ID 用於不限於特定句型的引擎層語義。Evidence 保存 CR 版本／條號、Q&A 編號／日期／問題範圍、卡片來源快照與必要原文；專案決定記日期、責任與理由，不假造官方編號。`decided_by.who` 為封閉值：`user` 表示經使用者裁定，`agents` 表示起草與審核的 agent 意見一致而依專案原則直接採用；參與者可另列，不另加標記欄位。

Official 表示來源直接支持；Generalized 表示由條文明文適用範圍或同類 Q&A 推得；Inferred 表示專案推定；Undecided 不能驅動自動結算或肯定提示。強度落在具体結論，不能因同份 ADR 有一條官方引用就整份升 official。使用者接受推定也不改變它的證據強度。

提示按強度說明依据。R-0001 保留 generalized，R-0006 保留 inferred，R-0009 為 official。S-008 的進化／超進化與 facet 次數分開記；S-019 的完整分配和部分成功也分開。卡片 meta 只引用登錄 ID，提示可依裁定引用實際 Q&A，不重複保存整份原文。

CR／Q&A 更新後反查裁定→IR→巨集→能力→測試；supersedes 保存被取代部分，effective view 僅採目前有效範圍。R-0002 不整筆刪除，仍提供結算條件與段落范围。來源互相衝突時保留 disputed 與相反證據，不以模型投票選官方答案。

## 考慮過的選項

| 選項                       | 為何不採／採用代價                                                                  |
| -------------------------- | ----------------------------------------------------------------------------------- |
| 每卡貼整段 Q&A             | 同一 Q 更新要改大量檔案，且容易留下不同日期與譯文；集中記錄才能知道哪些能力受影響。 |
| 只存網址                   | 網頁可能更新，日後無法重建採決時的版本；編號、日期、範圍與內容摘要不可省。          |
| 只記 official／非 official | 抹掉由 CR 直接類推與缺直接依據的專案推定差異，難以排序重審優先度。                  |
| 新裁定直接覆蓋舊檔         | R-0002 的仍有效部分也會丟失，舊測試無法說明當時期望為何不同；採可追蹤的部分取代。   |

## 後果

輔助提示需介面語言回退，保留日文來源並清楚標本專案解讀。登錄新增裁定後不能自動將能力提升 verified；需要先更新依賴並執行相應測試。

## 未決事項

六項專案解讀已採用並登錄為 R-0010～R-0015，標 strength: inferred，不冒稱已有官方直接依據。證據正規化及前端提示長度待介面設計，但不能因此省掉 inferred 標記。

## 2026-10-05 欄位簡化

裁定登錄移除 `decided_by` 的決定者，日期以頂層 `decided_on` 保留，取代上列對該欄的要求。
`question`、`decision`、`evidence`、`strength`、`applies_to`、`hint`、`supersedes` 原樣保留，
來源本身的日期／版本與必要引文不刪；欄位清除不提升任何裁定的證據強度。
