# ADR-0018：翻譯資料驗證層簡化

狀態：已採用（2026-10-04）。契約見 [PR #309](https://github.com/gbaian10/sve-kit/pull/309) 與 [翻譯契約](../schema/translation-contract.md)。

## 背景

本專案提供非官方翻譯，譯錯可直接修正，成本低於持續維護逐筆核可證明。
2026-10-01 至 10-04 的工作回顧估計，翻譯相關 PR 約一半用於驗證與核可機制；
收據、雜湊鏈與只增不改的限制增加維護者操作，甚至讓改錯字也牽動 commit 改寫。
Git 與 PR 已能保存修改及審查歷史，無須在翻譯資料內再維護一套核可流程。

## 決定

模板功能全部保留：清冊、句型比對、定義、參數、譯文、術語、卡名、風味、加粗、
新卡自動套用與完整未匹配清單；代碼／詞彙資料一併簡化。
驗證只留自動且必要的結構、唯一鍵、引用、永久身分、來源適用性、覆蓋、參數與渲染檢查。
讀取驗當前資料的結構與引用，建置驗當前使用閉包一次。

移除翻譯採納的核可雜湊鏈、收據、只增不改、讀取時歷史重播及重播用環境版本鎖定，
取消首輪抽查與政策前置、逐筆雙模型綁定及額外的合併前手動檢查。
有效資料可在一般 PR 直接修改；來源、語義及索引所需的 hash 仍保留，索引由工具更新。
低信心譯文通過自動檢查即可直接顯示，標「待校對」，並可切回原文；結構錯誤或來源錯配者不渲染。

歷史留在 Git，不改寫既有 commit；既有 PR 審查、AI 歸因與維護者核可流程照舊。
卡片身分、跨區 ID、勘誤、裁定等非翻譯採納，以及來源歸檔責任，不因本決定放寬。

## 考慮過的選項

| 選項 | 取捨 |
| --- | --- |
| 維持原驗證層 | 能逐筆證明核可內容，但日常修字與套用模板承擔過高操作成本，不採用 |
| 全部改成逐張直接翻譯 | 可省去模板維護，但失去既有重用與一致性能力；維護者暫不採，日後可做比對實驗 |
| 保留模板、簡化驗證 | 採用；以自動必要檢查守住資料與渲染正確性，修改及審查歷史交給 Git／PR |

## 後果

不再提供逐筆「誰核可哪組 bytes」的正式證明；低信心內容可先供使用者閱讀並回報修正。
轉換必須保留有效資料、模板行為及未解項目，不能以刪除功能換取驗證簡化。
之後若要為翻譯資料新增任何證明、收據或不可變機制，須先取得維護者同意。
