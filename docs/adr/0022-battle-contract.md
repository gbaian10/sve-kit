# 本機與線上共用有型別的對戰契約

本機與線上各自定義格式，會讓輸入與可見性規則分岔。沿用 [ADR-0001](0001-engine-skeleton.md) 的單一權威，由 Rust 定義共用對戰契約；完整玩家盤面決定畫面狀態，呈現資料不構成規則歷史。此選擇增加投影與暫態管理的成本，換取共用驗答、可靠的畫面對齊及對手資訊隔離，具體義務見[對戰契約](../sim/battle-contract.md)。

## Considered Options

- 只送事件、由前端重建規則狀態：資料較少，但未知事件與漏失更新會令狀態分歧；完整盤面讓略過動畫仍可正確對齊。
- 只送快照、由前端猜差異：格式較簡單，但缺少動作原因、同時性與中途變化，無法正確呈現音畫。
- 用文字標籤補語義：容易快速做畫面，但標籤會成為另一份 API，難以可靠驗答及多語化；保留有型別的題目、答案與事件。
- 雙端完整引擎加中繼：可減少伺服器運算，但用戶端會取得對手秘密，還要維持兩端同步；線上權威由伺服器獨占，本機在 Worker 執行相同引擎與投影。
