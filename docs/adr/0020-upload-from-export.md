# ADR-0020：上傳直接讀匯出目錄，取消發布帳本

狀態：已採用（2026-10-06）。部分取代 [ADR-0015](0015-image-url-version.md) 與 [ADR-0016](0016-snapshot-retention.md)，範圍見「取代範圍」。

## 背景

原本的 2.0 上傳要求先建凍結包，再維護發布帳本與備份、獨立 checkpoint、預留號、耐久發布計畫，
並以部署級 writer lease 協調多個寫入者；文字 ID 碰撞索引與事件首次發布版號也記在帳本裡。
這些是為多人、多機與精確恢復設計的。本專案只有一位維護者、一台電腦，`export-offline` 已能產出完整的
2.0 預覽根，開發桶需要的只是把它傳上去；正式建置與發布閘門（#34）尚未實作。

## 決定

1. `r2 upload-v2` 直接讀 `export-offline` 的公開匯出根：依 `snapshots/preview/current.json` 只選該清單的引用閉包
   與其引用的卡圖，不讀私有目錄、建置 bundle、圖片庫或配方快取。不做凍結包。
2. 逐檔比對遠端，只上傳缺少或不同的檔案，寫入後從 origin 讀回比對；CDN 照常驗證，或明示 `--skip-cdn-verify` 略過；
   最後以條件寫入切換 `snapshots/versions/index.json`，previous 改為原本的 current。失敗後重跑同一命令即補傳。
3. 卡圖版本號改由匯出端配發：私有目錄的 `media-state.json` 只存高水位整數與最近一次匯出的各組比較狀態。
   每次匯出先消耗一個新號，失敗的匯出也不回收；比較基準是最近一次匯出，所以換圖、撤下後恢復與 A→B→A
   一律拿新號，未變的組沿用原號。要以不同 bytes 覆寫卡圖前，匯出會先刪掉 preview 指標。
4. 開發桶的版本索引以 `preview-` 版號寫入 current／previous entry；Index Schema 接受預覽版號。
   這只是開發 entry，不是正式發布；正式發布仍須重新建置並通過 #34 的閘門。
5. 移除：凍結包、發布帳本與其備份、獨立 checkpoint、預留號、耐久發布計畫與 attempt 紀錄、writer lease、
   維護者授權旗標與收據輸出、跨版本的文字 ID 碰撞索引、事件首次發布收據。`identity_change.data_version`
   不再承諾是事件首次發布的版號。
6. 回收（`r2 gc-v2`）只依遠端索引的 current／previous 計算保留集；不另保護在途上傳，不在上傳期間執行。

## 取代範圍

- ADR-0015「版本是最後變更的單調**發布** revision」改為匯出端高水位配發的 revision；URL 形狀、
  card／art 分組、純文字不換號、恢復與 A→B→A 換新號、失敗號不重用、最後切索引等其餘決定不變。
- ADR-0016「文字 ID 碰撞檢查改用耐久的精簡發布鍵索引，事件首次 data_version 用發布收據固定」一段取消；
  兩版快照與只留 current 卡圖的保留政策不變。
- ADR-0016「不能刪到仍保留的共用 blob 或合法在途發布」中的在途保護取消；改為上傳與回收不得同時執行。
  仍保留的共用 blob 照閉包保護。

## 考慮過的選項

| 選項 | 取捨 |
| --- | --- |
| 保留帳本，只刪凍結包 | 仍要初始化、備份、checkpoint 與恢復程序，為單人單機付出多人協作的成本 |
| 保留 writer lease | 能防兩個終端同時寫入，但需處理卡住的 lease 與人工恢復；單人可直接不同時執行 |
| 每次匯出換隨機 nonce 當版本 | 免配號狀態，但純文字更新也會讓全部卡圖 URL 換新、所有快取失效，且要改傳輸欄型 |
| 匯出端高水位＋最近比較狀態（採用） | 狀態只有一個小檔；換圖必換號、未變沿用；遺失狀態時無法自動察覺 |

## 後果

- 不再能精確證明中斷前做到哪一步；改為重跑上傳補齊，index 一律最後才切。
- `media-state.json` 遺失時會從 1 重新配號，可能撞到已被快取的舊 URL；它要隨既有備份保存並從備份還原。
- data_version 重用只對照遠端 current／previous；文字 ID 碰撞只在同一份快照內檢查；事件 data_version 只表示產出該列的建置。
- 不支援多台機器或多個終端同時上傳、或在上傳期間回收；這是使用規則，不由工具鎖定。
- 固定卡圖 key 的覆寫仍非原子：上傳途中舊快照可能讀到新 bytes，這是 ADR-0015 既有的取捨。
