# 專案用語

這份名詞表統一卡表、翻譯與對局之間的專案語言；中文用於討論，括號內英文供程式命名。
卡牌本身的關鍵字譯名由翻譯資料維護。

## 來源與卡表

**建置資料庫**（build DB）：
整理、驗證卡片資料所用的內部資料集合；與提供玩家的卡表快照分開。
_避免用_：線上卡表資料庫、玩家資料庫

**卡表快照**（snapshot）：
提供使用者的一整份有版號卡片資料，是查卡、建牌及模擬器共用的資料權威。
_避免用_：卡表資料庫、卡片 cache

**預覽快照**（preview）：
與卡表快照同格式、供隔離開發使用的產物，不是正式發布版。
_避免用_：測試發布版、正式快照

**快照清單**（manifest）：
描述一份卡表快照全部成員與其版本、完整性資訊的目錄。
_避免用_：抓取 manifest、版本索引

**版本索引**（version index）：
指向當前與直接前一發布版的入口，供版本切換使用。
_避免用_：快照清單、永久版本目錄

**抓取 manifest**（crawl manifest）：
記錄來源取得時間、網址與內容識別的觀測紀錄。
_避免用_：快照清單、下載快取

**來源歸檔**（source archive）：
保留原始來源內容、來源版本與觀測證據的不可變集合，供重建與查核。
_避免用_：卡表快照、穩定封存檔

**凍結輸入批次**（input batch）：
一次建置所採用的確定來源集合，包含對應的來源版本與抓取紀錄。
_避免用_：最新快取、發布批次

## 快照內容與載入狀態

**基本目錄**（basic catalog）：
所選版本與地區查卡搜尋所需的完整基本資料。
_避免用_：啟動包、首屏資料

**啟動包**（bootstrap）：
快照欄位分割中的基礎欄位部分，不代表基本目錄已完整。
_避免用_：基本目錄、搜尋就緒

**基本目錄容器**（basic catalog container）：
承載基本目錄內容的下載單位，包含穩定封存檔、最近包檔或共用檔。
_避免用_：卡包、單張卡資料

**穩定封存檔**（stable catalog archive）：
按固定分組合裝的舊卡包基本資料，是公開目錄的一部分。
_避免用_：來源歸檔、歷史快照

**最近包檔**（recent set file）：
最近卡包各自的基本目錄下載容器。
_避免用_：最新快照、增量包

**共用檔**（shared catalog file）：
基本目錄中跨卡包共用的實體或字典容器。
_避免用_：全卡包

**完整文字閉包**（complete text closure）：
指定版本全部文字及其必要引用的完整集合，含來源、官方對照及跨區依賴。
_避免用_：譯文總量、基本目錄

**卡號索引**（card number index）：
由官方卡號或暫定版次識別定位卡片與版次的按需資料。
_避免用_：搜尋基本目錄、跨區對照表

**基本文字就緒**（basic text ready）：
所需原文、譯文及其本地結構已齊備，可作普通文字呈現與搜尋的狀態。
_避免用_：完整檢視就緒、標註就緒

**日文依據／標註未備妥**（source / annotation pending）：
已宣告需要的日文來源或標註尚未取得完整內容的狀態。
_避免用_：無標註、來源錯誤

**完整檢視缺來源**（complete view missing source）：
所需資料已完整取得，仍缺少應存在的來源或標註目標的資料錯誤。
_避免用_：待下載、缺譯

**詳情分片**（detail shard）：
欄位分割中的其餘資料部分，例如效果、翻譯、Q&A 與裁定。
_避免用_：基本目錄之外的所有檔案、卡片全文

**歷史分片**（history shard）：
保存勘誤前卡文及其他歷史版本的快照內容。
_避免用_：前一版快照、來源歸檔

**分片**（shard）：
快照中可分開取得的小份資料；日常溝通也用此名稱指欄位分割。
_避免用_：卡包、資料表

**完整文字包**（full / text_all）：
全部文字分片的聯集容器，是完整下載同一份快照的替代形式。
_避免用_：另一份卡表、圖片包

**影像清單**（image manifest）：
描述卡圖來源、尺寸、版本及位置的資料集合，不含圖片本體。
_避免用_：卡圖、圖片庫

**卡包 media 分片**（set media shard）：
版次所屬卡包的卡圖顯示資料，包含可用狀態、尺寸及版本。
_避免用_：全域圖片索引、文字啟動包

**DSL 程式包**（dsl-programs）：
供對戰自動處理使用的卡片效果程式集合。
_避免用_：卡表快照、引擎支援狀態

## 卡片身分與採納

**卡**（card）：
規則上的同一張卡，不同地區或版次可以共用此身分。
_避免用_：版次、實體單張

**面**（face）：
卡片的一個面，一般卡與雙面卡分別有一面及兩面。
_避免用_：版次、插畫

**版次**（printing）：
某地區的一種實際印刷；卡號、稀有度、異畫或標誌不同可形成不同版次。
_避免用_：版本、卡

**人工版次**（manual printing）：
官方卡表未收錄而經人工採納的實體版次；人工顯示名稱不等於官方文字。
_避免用_：自創卡、官方版次

**序號補充**（serial supplement）：
對既有官方版次補充限量序號分母與註記的資料。
_避免用_：新版次、身分修復

**預設版次**（default printing）：
同一卡片在指定地區的預設展示版次。
_避免用_：原版、唯一版次

**一般版**（general printing）：
選取預設版次時，符合已採納的一般稀有度與加工分類的版次。
_避免用_：最早版、所有非異畫版

**構築規則引用**（construction rules ref）：
釘住一組有限構築規則及必要綜合規則依據的識別。
_避免用_：整副牌合法證明、引擎版本

**知識截至**（knowledge cutoff）：
本次來源與核對能支持的最後觀測時點。
_避免用_：發布日期、生效日期

**禁限覆蓋**（restriction coverage）：
指定地區、賽制及期間的限制資料已核對到什麼範圍。
_避免用_：牌組合法性、沒有禁限

**探索範圍**（discovery range）：
有來源依據支持公告清單完整的時間區間。
_避免用_：最舊公告日期、任意日期篩選

**構築名稱**（rules name）：
同地區在構築規則上視為同名的一組卡。
_避免用_：搜尋別名、卡片身分

**採納封套**（adoption envelope）：
把精確資料成員、來源及人工決定綁在一起的採納記錄。
_避免用_：一般資料檔、自動驗證通過

**插畫**（art）：
可供多個版次共用的一幅插畫。
_避免用_：卡圖、版次

**換皮卡**（reskin / same_rules_reskin）：
卡名或角色不同，但經核對與指定原卡規則相同的另一張卡。
_避免用_：同名卡、異畫

**地區**（region）：
官方發行的日版或英版，分別稱 jp、en。
_避免用_：介面語言、玩家所在地

**表記未定**（wording pending）：
來源文字觀測差異或採納順序尚未解決的狀態；暫顯文字不代表已採納正文。
_避免用_：缺卡、翻譯待校對

**身分修復**（identity repair）：
以明示採納決定修正既有卡片歸屬，而保留永久版次身分的操作。
_避免用_：重新配號、修正譯名

**決定續版**（decision supersession）：
保留舊記錄並追加精確新內容與新決定，使有效投影採用新決定。
_避免用_：覆寫舊決定、追認核可

**商品身分對照**（product identity map）：
永久商品身分與官方來源識別線索的人工採納對照。
_避免用_：商品內容核可、卡包收錄表

## 語言與翻譯

**卡面語言**（card edition）：
使用者選擇查看的官方發行版本，決定卡圖及原文。
_避免用_：介面語言、翻譯語言

**介面語言**（UI language）：
介面文字及譯文的顯示語言，與卡面語言分開選擇。
_避免用_：地區、卡面語言

**翻譯上下文**（translation context）：
原文字單元與特定語義解讀的組合，讓同字異義可分開選譯文。
_避免用_：原文字串、翻譯用途

**翻譯用途**（translation use）：
一段文字在原文引用者、欄位與段落中的精確用途。
_避免用_：歸檔 owner、來源綁定

**翻譯選用**（translation selection）：
每個上下文與目標語言目前選定的本站譯文。
_避免用_：官方對照、核可收據

**選詞**（glossary choice）：
指定概念與語言的當前譯名。
_避免用_：概念身分、句框架

**術語引用**（term reference）：
指向永久概念或詞彙身分的引用，與當前顯示名稱分開。
_避免用_：譯名字串、全文搜尋命中

**加粗選擇**（glossary emphasis choice）：
規則術語是否加粗的可修訂採納決定。
_避免用_：文字搜尋結果、逐位置標註

**參數辨識政策**（parameter recognition policy）：
界定哪些來源值、角色與適用條件可以被辨識的具名規則集合。
_避免用_：逐詞核可、任意字串槽

## 四層翻譯

**句框架**（frame）：
整行來源的固定語義、葉槽及語義變體，可跨卡重用。
_避免用_：中文句子、固定譯文模板

**語義葉值**（typed leaf value）：
有明確型別、角色及合法域的來源值，由翻譯與效果 DSL 共用。
_避免用_：自由字串參數、中文抽詞

**來源綁定**（source binding）：
句框架在某個精確來源用途上的實例，包含葉值及其出現位置。
_避免用_：翻譯用途、字詞去重表

**文法形式**（form）：
依基礎名稱及語境產生量詞、方位或動詞融合的有限呈現規則。
_避免用_：遊戲動作、DSL 巨集

**名詞片語**（noun phrase / NP）：
在封閉文法內組合葉引用的呈現結構，允許只涵蓋部分修飾。
_避免用_：完整語義樹、自由文字槽

**渲染投影**（render projection）：
由句框架、葉值、譯文與文法形式得到的文字及概念位置。
_避免用_：來源語義、規則本體

**標註集合**（annotation set）：
某個精確文字單元及其概念出現位置的組合。
_避免用_：詞彙表、加粗字串清單

**欄位標註**（field annotation）：
某個公開原文用途所帶的非空標註集合，與有沒有譯文分開。
_避免用_：翻譯用途、建置採納記錄

**標註概念**（annotation concept）：
被公開標註引用的概念說明與已確認卡名目標。
_避免用_：建置詞彙表、採納決定

**公開文字指標**（public text pointer）：
指向翻譯依據或官方對照之精確公開原文用途的引用。
_避免用_：來源歸檔位置、採納收據

**引用出現位置**（occurrence）：
一個葉引用在來源或渲染文字中實際出現的一次；同詞重複出現仍各有位置。
_避免用_：唯一詞彙、去重概念

**語義變體**（semantic variant）：
相同表面句型中會影響規則解讀的分支，例如打出時目標與結算時選擇。
_避免用_：替代譯詞、NP 覆蓋

**規則投影類別**（projection kind）：
來源片段承擔的規則責任分類：本體、旗標、卡片欄位、已知無執行內容或未定。
_避免用_：呈現形式、引擎支援等級

**框架本體**（frame body）：
句框架所對應的有版本效果 DSL 內容，與翻譯呈現及審核資格分開。
_避免用_：合格巨集、譯文

**合格巨集**（qualified macro）：
滿足不同卡數、獨立審核、適用域與邊界測試要求的框架本體版本。
_避免用_：高頻框架、自動 verified

## 規則與對局

**效果 DSL**（effect DSL）：
描述卡片效果、供規則引擎處理的專案撰寫語言。
_避免用_：卡片譯文、任意腳本

**裁定**（ruling）：
本專案登錄的規則判讀及其依據，涵蓋官方直接支持、類推、專案推定與未定結論。
_避免用_：官方答案、模型共識

**對局工作區**（match workspace）：
進行中對局的可恢復工作資料，與結束後的回放歸檔分開。
_避免用_：回放歸檔、開發工作區

**權威狀態**（authoritative state）：
引擎持有的完整對局狀態，含私有資訊及待續程序。
_避免用_：玩家畫面、公開狀態

**玩家觀察**（Observation）：
依特定玩家可知範圍呈現的對局資料。
_避免用_：完整 state、權威回放

**權威回放**（authoritative replay）：
保存權威決定及隨機輸入的對局重播資料，觀看時仍受資訊可見性限制。
_避免用_：公開歷史卡表、操作錄影

**引用層級裁定 pending**（reference-level ruling pending）：
舊適用域未知時保留的原始裁定引用，尚無有效新目標。
_避免用_：已解用途映射、有效裁定引用

**用途層級裁定 resolution**（occurrence-level ruling resolution）：
已知完整舊域後，逐個精確來源用途對新句框架的承接判定。
_避免用_：引用層級 pending、整筆裁定核可
