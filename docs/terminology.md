# 專案用語

討論、文件、issue 與程式命名一律使用這裡的名稱。中文用於討論與文件，英文用於程式、檔名與欄位。
新增或改名時先改這份，再改其他地方。

卡牌遊戲本身的術語（關鍵字、能力名稱等）的譯名不在這裡，屬於翻譯資料。

## 程式分層

| 中文 | 英文（程式／檔名） | 指什麼 |
| --- | --- | --- |
| **共用基礎** | core | carddb 各層共用的 JSON／YAML 邊界、嚴格型別、日期、authored 路徑與純來源溯源資料；不依賴卡片語意或建置 DB |
| **共用契約** | contracts | build 與 export 共用的公開快照 schema、profiles、欄位 descriptor 與模板參數形狀；只依賴共用基礎，不包含辨識規則或建置／匯出流程 |
| **來源取得** | ingest | 抓取協調、HTTP、manifest 與不可變來源歸檔；抓取協調可呼叫純解析，低階 HTTP／歸檔不依賴 crawler 或工作流程 |
| **純解析** | parse | 來源 bytes 轉成欄位與觀測；不載入 authored、不建置 DB；身分與 QA 的領域適配留各領域 |
| **建置基礎設施** | build | DB schema、編譯、型別化資料列、完整性檢查與建置輸出；scalar 值域集中在 scalars 模組 |
| **資料領域** | domains | authored 載入、官網資料合併、領域驗證與 DB 投影；翻譯和數位版各按職責分子套件，不依賴 workflows 或 CLI |
| **工作流程** | workflows | 串接來源讀取、領域準備、建置及匯出的跨階段入口；下層不依賴此層或 CLI |

## 資料的兩層

| 中文 | 英文（程式／檔名） | 指什麼 |
| --- | --- | --- |
| **建置資料庫** | build DB | 我們整理與驗證資料用的 SQLite，含來源、審核紀錄與歷史；只在建置時使用，不給使用者 |
| **卡表快照** | snapshot | 發布給使用者的整份卡片資料，每次發布有一個版號（`data_version`） |
| **預覽快照** | preview | 與卡表快照同格式、隔離存放的開發產物；不發布給使用者 |
| **快照清單** | manifest | 快照的目錄：包含哪些檔、雜湊、大小與版號；前端第一個讀取的檔 |
| **版本索引** | version index | current＋previous 的發布入口；供更新過渡，不提供永久歷史定位 |
| **來源歸檔** | source archive | repo 外按內容定址保留的原始 bytes、來源版本與觀測收據 |
| **凍結輸入批次** | input batch | 釘住來源歸檔閉包與抓取 manifest 一致副本的不可變建置輸入 |

來源歸檔與凍結輸入批次供重建與查核，不是玩家下載的卡表快照；契約見 [來源歸檔與凍結輸入](schema/source-archive.md)。

卡表快照是卡片資料的唯一權威（見 `AGENTS.md`）。前端可以快取它，但不另外維護卡表。
預覽快照與卡表快照使用同一傳輸格式，但僅供非公開開發，不發布給使用者，只會以 `preview-` 版號寫進開發桶的版本索引，也不提供永久分享碼或回放相容保證；隔離規則見 [快照格式 §4.2](schema/snapshot-format.md#42-預覽快照)。

## 卡表快照的內容

| 中文 | 英文 | 指什麼 |
| --- | --- | --- |
| **啟動包** | bootstrap | 第一個下載的小檔：卡號、卡名、數值與篩選索引；載入後即可查卡、篩選 |
| **詳情分片** | detail shard | 效果全文、翻譯、Q&A、裁定等，分成多個小檔在背景補齊 |
| **歷史分片** | history shard | 勘誤前的卡文與其他歷史版本 |
| **分片** | shard | 以上各種小檔的統稱；未變動的分片跨版本內容與檔名相同 |
| **完整文字包** | full（`text_all`） | 所有文字分片的聯集容器，供完整下載或工具匯入；與分片是替代的下載方式，不重複下載 |
| **影像清單** | image manifest | 卡圖的 metadata（來源、尺寸、版本與定位規則），與文字分片分開載入；不含圖片本身 |

2.0 的「卡包 media 分片」指 printing.home_set 所屬、含狀態／尺寸／card_version／art_version 的影像顯示投影；role 仍為 images、partition 仍為 detail，不是另一份獨立卡表。

技術文件中的「欄位分割」（fragment）指同一集合的欄位分放在啟動包與詳情分片兩邊，每個欄位值只存一處。
日常溝通一律說「分片」。

## 另外下載、不計入卡表快照容量

| 中文           | 英文         | 指什麼                                                         |
| -------------- | ------------ | -------------------------------------------------------------- |
| **卡圖**       | card images  | 卡圖檔案本身，放在 CDN，看到才下載；快照內只有卡圖清單         |

## 卡片資料模型

| 中文 | 英文 | 指什麼 |
| --- | --- | --- |
| **卡** | card | 規則上的同一張卡；不同地區、不同版本的印刷共用同一張卡 |
| **面** | face | 卡的一面；一般卡一面，雙面卡兩面 |
| **版次** | printing | 某地區的某個實際印刷：卡號、稀有度、異畫、標誌等不同就是不同版次 |
| **人工版次** | manual printing | 官方卡表未收錄、經人工採納的實體版次；人工顯示名稱不等於官方卡文 |
| **序號補充** | serial supplement | 在既有官方版次上補卡面序號分母與註記，不新增版次或改身分 |
| **預設版次** | default printing | 同一卡片在指定地區的預設展示版次；更換預設不改既有版次網址 |
| **一般版** | general printing | 預設版次選取所用的稀有度與加工分類；稀有度白名單已核可為 BR/SR/GR/LG 及英版同類，加工採納門檻沿既有契約；卡框／標誌缺證據仍未知 |
| **構築規則引用** | construction rules ref | 釘住有限規則定義與必要 CR 引用的不可變識別；資料可查不代表整副牌算法已支援 |
| **知識截至** | knowledge cutoff | 本次來源與核對能支持的最後觀測時點；不同於發布時間或未來排程 |
| **禁限覆蓋** | restriction coverage | 指定地區、賽制與期間的限制資料是否已完整核對；部分覆蓋不表示沒有其他限制 |
| **探索範圍** | discovery range | 官方索引及分頁能證明公告清單無缺漏的時間區間；須有來源定位與核對，不能只取最舊標題推定 |
| **構築名稱** | rules name | 同地區規則視為同名的群組；不同於搜尋別名，不改卡片永久身分 |
| **採納封套** | adoption envelope | 綁定精確記錄成員、內容 hash、來源與人工決定的輸入結構；格式通過不代表資料已核可 |
| **插畫** | art | 一幅插畫；多個版次可以共用同一幅插畫 |
| **換皮卡** | reskin (`same_rules_reskin`) | 卡名或角色不同、經核對與指定原卡規則相同的另一張卡；不代表構築同名 |
| **地區** | region | `jp` 或 `en`，指官方發行的版本，不是介面語言 |
| **表記未定** | wording pending | 觀測差異或採納順序尚未解決；仍可顯示版次文字與候選，暫時顯示的文字不等於已採納 current |
| **身分修復** | identity repair | 以明確採納事件修正既有卡片歸屬，永久版次與整數 ID 不變 |
| **決定續版** | decision supersession | 追加精確新內容與新決定供有效投影選用，舊記錄及決定保留；身分登錄格式已核可，撤回也須指名原修復並追加新決定 |
| **商品身分對照** | product identity map | 人工採納的永久商品 ID 與官方來源識別線索的對照；不確認商品名稱、日期或收錄內容 |

## 語言

| 中文         | 英文         | 指什麼                                       |
| ------------ | ------------ | -------------------------------------------- |
| **卡面語言** | card edition | 看哪個地區的卡：決定卡圖與原文（日版／英版） |
| **介面語言** | UI language  | 介面文字與翻譯的語言：繁中、日文、英文       |

兩者分開設定，互不影響。

| 中文 | 英文 | 指什麼 |
| --- | --- | --- |
| **翻譯上下文** | translation context | 原文字單元與已採納語義變體的組合；同字異義可分開選譯文 |
| **翻譯用途** | translation use | 精確指向原文所屬的引用者、欄位及段落位置，不是檔案的歸檔 owner |
| **翻譯選用** | translation selection | 每個上下文與目標語言的唯一有效本站譯文；官方 counterpart 另按 owner 選用 |
| **選詞** | glossary choice | 對指定概念與語言採納的一個譯名，變更追加決定，生成譯文自動重算 |
| **術語引用** | term reference | 以 kind/key 定位 glossary 永久概念或 vocabulary 詞彙，與顯示名分開 |
| **加粗選擇** | glossary emphasis choice | rule_term 的可修訂加粗採納紀錄；其他術語由型別推導 |
| **委託採納收據** | delegated adoption receipt | 保存具體委託範圍、實際協調者與決定事件，不算維護者親自核可 |
| **模板來源清冊** | template source inventory | 每次建置從封存來源產生的句型位置清單；不存 Git，項目 ID 不含 store 與封存批次 |
| **參數辨識政策** | parameter recognition policy | 核可精確來源位置的數值／引用角色；以條件 hash、matcher 與真實事件釘住，獨立於模板定義及譯本採納 |

## 規則與效果

| 中文 | 英文 | 指什麼 |
| --- | --- | --- |
| **對局工作區** | match workspace | 進行中對局的可恢復工作資料；與結束後的回放歸檔分開，見 [對局儲存邊界](deployment/matches.md) |
| **權威狀態** | authoritative state | 引擎保存的完整對局狀態，含私有資訊與續體；不能直接送給玩家 |
| **玩家觀察** | Observation | 權威狀態依玩家可見範圍投影的資料；決定另以獲授權的 DecisionView 提供 |
| **權威回放** | authoritative replay | 保存權威決定與隨機輸入版本的重播資料；觀看時仍須套資訊投影，見 [回放邊界](deployment/replays.md) |

| 中文         | 英文   | 指什麼                                                                   |
| ------------ | ------ | ------------------------------------------------------------------------ |
| **效果 DSL** | DSL    | 描述卡片效果的撰寫語法，規格在 `docs/dsl/`，Schema 在 `dsl/`             |
| **IR**       | IR     | DSL 編譯後引擎實際執行的中間表示                                         |
| **ADR**      | ADR    | 架構決策紀錄，在 `docs/adr/`，編號全 repo 共用一個序列                   |
| **裁定**     | ruling | 官方沒有明說時本專案採用的判讀，編號 `R-0001` 起，在 `authored/rulings/` |
