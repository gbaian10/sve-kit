# 文件中的來源引用與授權

`docs/` 的專案自有規格、解讀與範例程式依 [LICENSING.md](../LICENSING.md) 採 Apache-2.0。
其中引用的官方卡名、商品名、卡文、規則與 Q&A，以及其他第三方文字，不在本專案授權內；
即使它們出現在表格、行內程式碼或 YAML／JSON 範例中，也不改變其來源權利。
權利仍屬各自權利人。來源連結與引用標示不是重新授權，也不限制法律或權利人另行允許的使用。

## 如何分辨

- **官方原文或節錄**：卡文引用區塊、以卡號對照的日英卡名，以及引用規則／Q&A 的日英短句。
  原文中的圖示可能以 `{…}` 或 `【…】` 轉寫；省略號、變數占位或略去括號註解須依該例說明閱讀，
  不能當作完整卡面或逐字全文。
- **專案整理與解讀**：中文說明、類型與語法設計、測試結果、推導步驟及 DSL 程式。
  這些自有部分依文件授權；其中嵌入的官方名稱與原文仍排除。
  `R-…` 裁定、`strength: inferred` 或 `generalized` 是專案判讀紀錄，不是官方新增裁定。
- **來源定位**：卡號、CR 條號、Q 編號、卡面／行索引用來找出依據，不是權利許可。
  不把所有日文、英文或引號內容一律視為官方原文；專案變數、示意值與轉述仍須分開辨識。

## 來源與版本

| 標記 | 來源與讀法 |
| --- | --- |
| 卡號、卡名與卡文 | [日文官方卡表](https://shadowverse-evolve.com/cardlist/)；[英文官方卡表](https://en.shadowverse-evolve.com/cards/)。以文件寫出的原卡號及地區定位，日英卡號不自行去後綴配對。 |
| `CR`＋條號 | [官方規則入口](https://shadowverse-evolve.com/rules/)。DSL 1.0 指定 CR 1.27.0；其他文件依各自記錄的版本，不能把目前官網版本當成舊文引用版本。 |
| `Q`＋編號 | [日文官方卡片 Q&A](https://shadowverse-evolve.com/question/card/)、[一般規則 Q&A](https://shadowverse-evolve.com/question/faq/)，以及對應地區的官方卡片頁。日英答覆可能不同；例如 M0 的 Q302 比較須保留兩種語言。 |
| `卡號#面/text/行`、`卡號#面/section:段/行` | DSL 卡例在 2026-09-26 凍結卡表的來源位置，面、段與行從 0 起算；不是網站錨點。卡例旁的官方頁連結供定位，頁面可能已更新。 |
| `R-…`、`C§…`、題號 | 專案的 [裁定登錄](../authored/rulings/)、[情境契約](../tests/rules-scenarios/CONTRACT.md) 與 [定案題庫](../tests/rules-scenarios/questions/)。其中的來源引文保留其原權利；其餘專案內容依各自路徑授權。 |

引用應保留所在文件的卡號、Q／CR 編號、版本與來源位置。本文不替舊文件更新引文、補猜缺失的來源，
也不把變動中的官網頁面當成歷史文字的逐字證明。
